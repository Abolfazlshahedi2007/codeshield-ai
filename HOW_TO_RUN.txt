================================================================================
       راهنمای گام‌به‌گام راه‌اندازی و اجرای محلی پروژه «سپر کد» (CodeShield AI)
================================================================================

سلام! این راهنمای جامع برای راه‌اندازی، نصب پیش‌نیازها و اجرای سرور محلی پروژه
«سپر کد» (CodeShield AI) آماده شده است.


--------------------------------------------------------------------------------
پیش‌نیازها (Prerequisites):
--------------------------------------------------------------------------------
۱. پایتون نسخه 3.10 یا بالاتر (توصیه می‌شود پایتون 3.11 یا 3.12 باشد).
   - موقع نصب پایتون در ویندوز حتماً تیک گزینه "Add Python to PATH" را بزنید.
۲. نرم‌افزار Git (برای کلون و دریافت آخرین نسخه مخزن).
۳. یک مرورگر وب مدرن (گوگل کروم، فایرفاکس، مایکروسافت اج یا سافاری).


--------------------------------------------------------------------------------
گام ۱: دریافت پروژه و ورود به پوشه
--------------------------------------------------------------------------------
ابتدا ترمینال یا CMD را باز کرده و دستورات زیر را اجرا کنید:

    git clone git@github.com:Abolfazlshahedi2007/codeshield-ai.git
    cd codeshield-ai

(اگر پروژه را به صورت فایل فشرده دریافت کرده‌اید، آن را اکسترکت کنید و در ترمینال
با دستور cd وارد پوشه اصلی codeshield-ai شوید).


--------------------------------------------------------------------------------
گام ۲: ایجاد و فعال‌سازی محیط مجازی پایتون (Virtual Environment)
--------------------------------------------------------------------------------
چرا محیط مجازی؟
پایتون پکیج‌ها را به صورت پیش‌فرض در کل سیستم نصب می‌کند. محیط مجازی یک پوشه
مستقل و ایزوله می‌سازد تا تمام پکیج‌های این پروژه فقط درون همین پوشه نصب شوند
و با دیگر برنامه‌ها و نسخه‌های پایتون سیستم شما تداخلی نداشته باشند.

۱. دستور ساخت محیط مجازی:
در ترمینال، داخل پوشه codeshield-ai دستور زیر را بنویسید:

    python -m venv venv

(این دستور پوشه‌ای به نام venv در کنار فایل‌های پروژه ایجاد می‌کند).

۲. دستور فعال‌سازی محیط مجازی:

الف) اگر در ویندوز از CMD (Command Prompt) استفاده می‌کنید:
    venv\Scripts\activate.bat

ب) اگر در ویندوز از PowerShell یا ترمینال VS Code استفاده می‌کنید:
    venv\Scripts\Activate.ps1

    * رفع خطای احتمالی در پاورشل (ExecutionPolicy):
    اگر با خطای قرمز رنگ running scripts is disabled روبرو شدید، یک‌بار دستور زیر
    را در پاورشل اجرا کنید و کلید Y را بزنید، سپس مجدداً اسکریپت بالا را اجرا کنید:
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

ج) اگر در سیستم‌عامل لینوکس یا مک (macOS) هستید:
    source venv/bin/activate

۳. از کجا بفهمیم فعال شده است؟
در ابتدای خط فرمان ترمینال، عبارت (venv) در پرانتز اضافه می‌شود، مثلاً:
    (venv) C:\Users\Username\codeshield-ai>


--------------------------------------------------------------------------------
گام ۳: نصب وابستگی‌ها و پکیج‌ها (requirements.txt)
--------------------------------------------------------------------------------
در حالی که عبارت (venv) در ابتدای خط فرمان فعال است، دستور زیر را اجرا کنید:

    pip install -r requirements.txt

چه اتفاقی می‌افتد؟
کتابخانه‌های فلسک (Flask)، ارتباطات وب (Requests)، اتصال دیتابیس (SQLAlchemy)،
مدیریت کاربران (Flask-Login) و ابزار تست خودکار (Pytest) دانلود و نصب می‌شوند.

* نکته اختیاری: اگر پیامی مبنی بر آپدیت pip دیدید، می‌توانید دستور زیر را بزنید:
    python -m pip install --upgrade pip


--------------------------------------------------------------------------------
گام ۴: اجرای سرور محلی (Local Server)
--------------------------------------------------------------------------------
در همان ترمینال با محیط فعال، دستور زیر را برای اجرای سرور فلسک بزنید:

    python app.py

خروجی در ترمینال به شکل زیر نمایش داده می‌شود:
    * Serving Flask app 'app'
    * Debug mode: on
    * Running on http://127.0.0.1:5000
    Press CTRL+C to quit

این یعنی سرور با موفقیت بالا آمده و پایگاه‌داده سبک SQLite (در پوشه instance)
به طور خودکار آماده به کار شده است.


--------------------------------------------------------------------------------
گام ۵: باز کردن و تست برنامه در مرورگر
--------------------------------------------------------------------------------
مرورگر اینترنت خود را باز کنید و آدرس زیر را وارد کنید:

    http://127.0.0.1:5000

نحوه تست سریع (بدون نیاز به ثبت‌نام دستی):
۱. در صفحه ورود، روی دکمه نارنجی‌رنگ «⚡ ورود به عنوان داور / مهمان (یک‌کلیکی)»
   کلیک کنید تا بلافاصله وارد میزکار اصلی شوید.
۲. در بالای ویرایشگر، از منوی «📂 نمونه‌های آماده ▾» یکی از نمونه‌های پایتون،
   پی‌اچ‌پی یا جاوااسکریپت را انتخاب کنید.
۳. دکمه بزرگ آبی «🔍 اسکن سریع امنیت (آفلاین)» را بزنید تا آسیب‌پذیری‌ها و امتیاز
   امنیتی در رآکتور سه‌بعدی شیشه‌ای نمایش داده شود.
۴. برای اصلاح کد، می‌توانید روی دکمه سبز «⚡ اصلاح آفلاین (الگوی امن دمو)» بزنید تا
   کد بدون نیاز به اینترنت فوراً بازنویسی شده و نمره ۱۰۰/۱۰۰ را دریافت کند.


--------------------------------------------------------------------------------
گام ۶: اجرای تست‌های خودکار برای اطمینان از سلامت کدها
--------------------------------------------------------------------------------
برای بررسی درستی تمام توابع، اسکنر و اندپوینت‌ها، دستور زیر را در ترمینال بزنید:

    python -m unittest discover tests

نتیجه باید نشان دهد که تمام ۲۱ تست بدون هیچ خطایی پاس شده‌اند:
    Ran 21 tests in 0.440s
    OK


--------------------------------------------------------------------------------
گام ۷: خاموش کردن سرور و خروج از محیط مجازی
--------------------------------------------------------------------------------
۱. برای توقف سرور در ترمینال:
   کلیدهای ترکیبی Ctrl + C را همزمان فشار دهید.

۲. برای خروج از محیط مجازی:
   دستور زیر را تایپ کنید:
   deactivate
