# CodeShield AI (سپر کد)

سامانه تحلیل ایستای سورس‌کد (Static Code Analysis) و ممیزی خودکار جهت کشف آسیب‌پذیری‌های امنیتی، باگ‌های منطقی و افت‌های کارایی در زبان‌های Python، PHP و JavaScript با قابلیت اصلاح هوشمند کد.

---

## ویژگی‌های کلیدی

- **تحلیل امنیتی (Security Scanner):** شناسایی تزریق SQL (SQL Injection)، اسکریپت‌نویسی بین‌سایتی (XSS)، اسرار و کلیدهای هاردکد شده (Hardcoded Secrets)، توابع پرخطر (`eval`, `exec`) و رمزنگاری ضعیف.
- **تحلیل ساختاری و منطقی (AST Engine):** استفاده از ماژول `ast` پایتون جهت کشف آرگومان‌های پیش‌فرض تغییرپذیر (Mutable Default Arguments)، کدهای غیرقابل دسترس (Unreachable Code)، بلعیدن خاموش خطاها (`except: pass`)، حلقه‌های با پیچیدگی زمانی بالا و نشت منابع فایل بدون بلوک `with`.
- **تشخیص گلوگاه‌های کارایی:** ردیابی خطاهای فراخوانی I/O و کوئری‌های تکراری درون حلقه (N+1 Problem) در زبان‌های پایتون، PHP و جاوااسکریپت.
- **اصلاح دوگانه سورس‌کد (Remediation):** بازنویسی برخط کدها از طریق Google Gemini API با پاسخ ساختاریافته Native JSON، همراه با موتور امن‌ساز آفلاین (الگوهای از پیش تاییدشده با نمره ۱۰۰).
- **کنسول کاربری و ابزارها:** ویرایشگر CodeMirror با هایلایت اختصاصی، پرش به خطوط خطا، نمودار امتیازدهی Chart.js، تفکیک ریزامتیازهای امنیت و کیفیت، فیلتر دسته‌بندی‌ها، بارگذاری فایل محلی و ایمپورت مستقیم از مخازن گیت‌هاب با محافظت در برابر SSRF.

---

## فناوری‌های مورد استفاده

- **Backend:** Python 3, Flask, Flask-Login, Flask-SQLAlchemy, Python AST
- **Frontend:** CodeMirror 5, Chart.js, Marked.js, DOMPurify, Vanilla JS
- **Database:** SQLite (SQLAlchemy ORM)
- **AI Integration:** Google Gemini API
- **Testing:** Pytest / Unittest

## نصب و راه‌اندازی سریع

### ۱. پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- ابزار `pip`

### ۲. راه‌اندازی محیط و نصب وابستگی‌ها

```bash
# ایجاد و فعال‌سازی محیط مجازی
python -m venv venv

# لینوکس و مک:
source venv/bin/activate
# ویندوز:
.\venv\Scripts\activate

# نصب پکیج‌ها
pip install -r requirements.txt
```

## پیکربندی متغیرهای محیطی

تنظیمات برنامه از طریق فایل `.env` در ریشه پروژه قابل تعیین است:

| متغیر | مقدار پیش‌فرض | توضیحات |
| :--- | :--- | :--- |
| `SECRET_KEY` | کلید پیش‌فرض توسعه | کلید امضای نشست‌های کاربری (Session) |
| `GEMINI_API_KEY` | اختیاری (خالی) | کلید دسترسی به Google Gemini API جهت اصلاح برخط |
| `DATABASE_URL` | `sqlite:///codeshield.db` | آدرس اتصال پایگاه داده |

> [!NOTE]
> در صورت عدم تنظیم `GEMINI_API_KEY`، تمامی قابلیت‌های اسکن محلی و دکمه «اصلاح آفلاین» به طور کامل و رایگان کار خواهند کرد.

## اجرا و ورود به سامانه

برای اجرای سرور توسعه دستور زیر را وارد کنید:

```bash
python app.py
```

- **آدرس دسترسی:** `http://127.0.0.1:5000`
- **حساب کاربری پیش‌فرض (داور):**
  - نام کاربری: `داور`
  - رمز عبور: `demo1234`
  - همچنین در صفحه ورود دکمه «ورود سریع داور و مهمان» جهت دسترسی تک‌کلیکی فراهم است.

## ساختار فایل‌های اصلی پروژه

```text
codeshield-ai/
├── app.py                  # کنترلرها، مسیرهای وب و اندپوینت‌های API
├── database.py             # مدل‌های پایگاه داده (کاربران و سوابق اسکن)
├── scanner.py              # موتور تحلیل ایستا (Regex Rules و Python AST)
├── ai_fixer.py             # الگوهای آفلاین و پردازش اصلاح خودکار
├── requirements.txt        # وابستگی‌های پایتونی پروژه
├── templates/              # قالب‌های Jinja2 (داشبورد، تاریخچه، ورود)
├── static/                 # کدهای CSS، جاوااسکریپت و پروتوتایپ‌ها
└── tests/                  # آزمون‌های واحد و امنیتی پروژه
```
