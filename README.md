# 🛡️ CodeShield AI (سپر کد)
> سامانه پیشرفته تحلیل ایستای کد، تشخیص آسیب‌پذیری‌های امنیتی، باگ‌های منطقی و گلوگاه‌های پرفورمنسی (به سبک کامپایلرهای مدرن)

---

## 🌟 ویژگی‌های کلیدی پروژه

* **🛡️ موتور تحلیل امنیت (Security Audit):** شناسایی آسیب‌پذیری‌های رایج (مانند SQL Injection، XSS، توکن‌های هاردکد شده و توابع خطرناک `eval`).
* **🧠 موتور تحلیل منطقی و پرفورمنس (AST Engine):** تحلیل درخت نحوی کد پایتون به سبک کامپایلر Rust برای شناسایی باگ‌های مخفی مانند:
  * آرگومان‌های پیش‌فرض تغییرپذیر (`Mutable Default Arguments`)
  * گلوگاه‌های پرفورمنس و کوئری‌های حلقه‌ای (`N+1 Query Problem`)
  * حلقه‌های تودرتوی عمیق و پیچیدگی زمانی بالا ($O(n^3)$)
  * نشت منابع سیستم (`Resource Leaks` بدون بلاک `with`)
  * بلعیدن خاموش خطاها (`Silent Exception Swallowing`) و کدهای مرده (`Unreachable Code`).
* **📊 پنل کاربری سه‌بعدی و شیشه‌ای (3D UI):** رابط کاربری مدرن با تم‌های تیره/روشن، رآکتور کوانتومی امتیازدهی، ریزامتیازهای مجزا (امنیت در برابر کیفیت/پرفورمنس) و تب‌های فیلتر تفکیک‌شده.
* **💡 پیشنهادهای کامپایلر (Compiler Hints):** نمایش راهکارهای دقیق به سبک کامپایلرهای پیشرفته برای اصلاح سریع خطاها و پرش مستقیم با یک کلیک به خط مورد نظر در ویرایشگر.
* **✨ اصلاح هوشمند (AI Fixer & Offline Fallback):** قابلیت اصلاح خودکار کدها هم به صورت آنلاین از طریق **Google Gemini API** و هم به صورت آفلاین از طریق الگوی امن دمو با تاییدیه امتیاز ۱۰۰/۱۰۰.
* **🐙 قابلیت‌های پیشرفته:** بارگذاری فایل محلی، وارد کردن مستقیم کد از مخزن گیت‌هاب (با محافظت کامل در برابر SSRF) و تاریخچه کامل اسکن‌ها.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

* **Backend:** Python, Flask, Flask-Login, SQLAlchemy, Python AST module.
* **Frontend:** HTML5, CSS3 (Glassmorphism & 3D UI), JavaScript (ES6+), CodeMirror, Chart.js.
* **AI Integration:** Google Gemini API (با پشتیبانی از حالت JSON Native).

## 🚀 راهنمای نصب و راه‌اندازی سریع

1. **کلون کردن مخزن و ورود به پوشه پروژه:**
   ```bash
   git clone <repository-url>
   cd CodeShield-AI
   ```

2. **ایجاد و فعال‌سازی محیط مجازی (Virtual Environment):**
   ```bash
   python -m venv venv
   # در لینوکس / مک:
   source venv/bin/activate
   # در ویندوز:
   venv\Scripts\activate
   ```

3. **نصب وابستگی‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

4. **اجرای برنامه:**
   ```bash
   python app.py
   ```

5. **دسترسی به سامانه:**
   مرورگر خود را باز کرده و به آدرس زیر بروید:
   `http://127.0.0.1:5000`
   *(برای ورود سریع می‌توانید از حساب پیش‌فرض «داور» با رمز عبور `demo1234` استفاده کنید).*
